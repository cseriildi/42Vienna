# About the ft_transcendence project

You can find our ft_transcendence git repo [here](https://github.com/cseriildi/ft_transcendence). We collaborated on this with [Daniel](https://github.com/Csicsi), [Silas](https://github.com/SilasLovelace), [Tim](https://github.com/timofeykafanov) and [Dimash](https://github.com/zhakhand).

## Summary

The goal of this project is to create a web application that is a multiplayer Pong game with a tournament system. The project must have a frontend, a backend, and a database. The entire application must be containerized using Docker and run with a single command.

## Mandatory Part

- **Web Application:** Must be a web application with a frontend, backend, and a database.
- **Containerization:** Use Docker or another containerization solution.
- **User Management:** A basic user management system with secure login (hashed passwords, etc.).
- **Multi-user Support:** The website must support multiple users at the same time.
- **Frameworks:** Use a framework for both the frontend and backend.
- **Real-time Features:** Implement real-time features using WebSockets or similar technology.
- **User Interaction:** Include a chat system, user profiles, and a friends system.

## Bonus Part

- **AI Opponent:** Introduce an AI opponent for games.
- **Tournament System:** Implement a tournament system with matchmaking.
- **Advanced Chat:** Include features like blocking users, game invites from chat, and chat history.
- **Two-Factor Authentication (2FA):** Implement a complete 2FA system for users.
- **Monitoring:** Set up a monitoring system with Prometheus and Grafana.
